# 🇩🇿 Dzayer → Español 🇪🇸

A simple and interactive website that translates famous Algerian Darija expressions into natural, everyday Spanish.

🔊 Tap the speaker icon to hear the Spanish pronunciation.

### 🌐 Live App
https://algerientospanishh-elnp85ywdqqbwkhplvensj.streamlit.app/

### ✨ Features
- 🇩🇿 Algerian expressions
- 🇪🇸 Natural Spanish translations
- 🔊 Spanish pronunciation
- 🔎 Search expressions
- 🗂️ Categories
- 📱 Mobile-friendly design
- ⚡ Fast and easy to use

Made for Algerians learning Spanish. ❤️
